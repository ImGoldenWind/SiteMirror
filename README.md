# Site Mirror

Локальный desktop-инструмент для зеркалирования сайтов с поддержкой SPA, динамического рендеринга и WACZ-архивов.

Проект построен на **Electron**, **React**, **TypeScript** и использует два режима захвата:

* **Playwright** — встроенный режим для рендеринга страниц, обхода ссылок, сохранения ресурсов и скриншотов.
* **Browsertrix** — Docker-based режим для создания WACZ-архивов с последующим просмотром через ReplayWeb.page.

## Назначение

Site Mirror позволяет сохранить локальную копию сайта, включая страницы, статические ресурсы и архивы, а затем просмотреть результат прямо в приложении или во внешнем браузере.

Инструмент полезен для:

* локального архивирования сайтов;
* проверки сохранённой версии страницы без доступа к оригинальному сайту;
* работы с SPA-сайтами, где контент появляется после клиентского рендеринга;
* создания WACZ-архивов через Browsertrix.

## Возможности

* Захват сайтов через встроенный Playwright-краулер.
* Альтернативный режим захвата через Browsertrix и Docker.
* Поддержка SPA и динамически загружаемого контента.
* Сохранение страниц, ресурсов и скриншотов.
* Создание и просмотр WACZ-архивов.
* Локальный сервер для просмотра сохранённого сайта.
* Поддержка range-запросов для медиафайлов.
* Настройка глубины обхода и выходной директории.
* Отображение логов и прогресса в Electron-интерфейсе.
* Упаковка desktop-приложения через electron-builder.

## Требования

Перед запуском убедитесь, что установлены:

* **Node.js** — рекомендуется версия 18 или новее.
* **npm** — используется для установки зависимостей и запуска скриптов.
* **Docker** — нужен только для режима Browsertrix/WACZ.
* **Windows** — основная целевая платформа для сборки дистрибутива через NSIS.

Playwright-браузер Chromium устанавливается автоматически после `npm install` через `postinstall`-скрипт.

## Режимы захвата

### Playwright

Встроенный режим используется как основной fallback-механизм. Он запускает Chromium, рендерит страницы, обходит ссылки, сохраняет HTML, статические ресурсы и сопутствующие данные.

Этот режим подходит, если:

* Docker не установлен;
* нужен простой локальный захват сайта;
* достаточно сохранения страниц и ресурсов без WACZ-архива.

### Browsertrix

Browsertrix используется для создания WACZ-архивов. Для работы требуется установленный и запущенный Docker.

Перед запуском Browsertrix приложение проверяет доступность Docker через `docker info`. Если Docker недоступен, приложение переключается на встроенный Playwright-режим.

Browsertrix запускается через контейнер:

```text
webrecorder/browsertrix-crawler
```

Результат можно просматривать через ReplayWeb.page.

## Как работает приложение

1. Electron main process создаёт окно приложения.
2. Renderer-интерфейс отправляет IPC-команды, например:

   * `crawler:start`;
   * `dialog:select-output-directory`.
3. Main process проверяет доступность Browsertrix/Docker.
4. Если Browsertrix доступен, запускается WACZ-пайплайн.
5. Если Browsertrix недоступен, используется встроенный Playwright-краулер.
6. После завершения захвата запускается локальный сервер.
7. Пользователь получает ссылку для просмотра сохранённой копии.

## Локальный сервер

После завершения зеркалирования приложение поднимает локальный сервер, который отдаёт сохранённые файлы сайта.

Сервер:

* обслуживает HTML, CSS, JavaScript, изображения и медиа;
* поддерживает частичные range-запросы для корректного воспроизведения медиафайлов;
* добавляет CSP-заголовки;
* позволяет открыть результат в приложении или во внешнем браузере.

## Сборка дистрибутива

Для сборки production-версии выполните:

```bash
npm run dist
```

Скрипт сначала выполняет сборку проекта, затем запускает `electron-builder`.

Готовые артефакты помещаются в директорию:

```text
release/
```

Конфигурация вывода задаётся в `package.json` через `build.directories.output`.

## Примечания по Playwright

Во время `npm install` автоматически запускается `postinstall`-скрипт, который устанавливает Chromium:

```bash
PLAYWRIGHT_BROWSERS_PATH=0 playwright install chromium
```

Это означает, что браузер будет установлен локально для проекта и будет доступен приложению без дополнительной настройки.

## Примечания по Browsertrix

Для Browsertrix-режима требуется Docker.

Проверьте, что Docker установлен и запущен:

```bash
docker info
```

Если команда завершается с ошибкой, Browsertrix-режим не будет использоваться, а приложение переключится на Playwright.

## Отладка

При проблемах с запуском проверьте:

1. Установлены ли зависимости:

```bash
npm install
```

2. Установился ли Chromium для Playwright.

3. Запускается ли приложение в dev-режиме:

```bash
npm run dev
```

4. Доступен ли Docker, если используется Browsertrix:

```bash
docker info
```

5. Есть ли права на запись в выбранную выходную директорию.

## Разработка

Для локальной разработки:

```bash
npm install
npm run dev
```

Основная логика приложения находится в `src/main`, интерфейс — в `src/renderer`.

При изменении main process, preload или renderer-кода используйте dev-режим, чтобы быстрее проверять изменения.
